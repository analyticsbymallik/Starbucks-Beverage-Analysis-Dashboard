# Starbucks-Beverage-Analysis-Dashboard
Power BI dashboard analyzing Starbucks beverages based on calories, sugar, caffeine, beverage categories, and product distribution.


## Project Overview

This project is an interactive **Starbucks Beverage & Nutrition Analysis Dashboard** developed using **Microsoft Power BI**. The dashboard analyzes Starbucks beverage data based on calories, sugar, caffeine, beverage categories, and product distribution.

## Key Analysis

- Total number of beverages
- Average sugar content
- Average calories
- Average caffeine
- Average calories by beverage category
- Beverage category distribution
- Average caffeine by category
- Top 5 highest-caffeine beverages
- Starbucks global presence
- Interactive beverage preparation and protein range filters

## Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- CSV
- Data Cleaning
- Data Transformation
- Data Visualization
- KPI Analysis

## Files

- `StarBucks-Analysis.pbix` – Power BI dashboard
- `starbucks.csv` – Starbucks beverage dataset
- `directory.csv` – Starbucks store/location data
- `Screenshot...png` – Dashboard preview

## Key Insights

The dashboard provides an interactive way to compare Starbucks beverages based on their nutritional characteristics and caffeine content. It helps identify high-calorie and high-caffeine beverage categories and provides an overview of beverage distribution and Starbucks presence.
